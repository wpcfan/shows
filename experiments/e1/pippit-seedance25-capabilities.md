## 2. 官方 Prompt 写法（对 E1/生产 prompt 的约束）

- 参考类：写清「谁参考谁、参考什么、不参考什么」；按上传顺序编号（图 1/视频 1/音频 1）并逐一绑定。
- 首尾帧：写在 prompt 第一句（见上表）。
- 时间戳：以 1 秒为单位、时间轴连续（避免 "0-3s…5-6s" 跳跃）；支持时间点与相对时间。
- 编辑类：写明修改范围与 A→B 过程，可配合时间戳。
- 负向控制：明确「不要字幕 / 无 bgm / 不要任何声音」等。

## 3. 实测复核（2026-09-14，4 次生成）

| 验证 | SSIM | 结论 |
|---|---|---|
| prompt-first（单图参考 + prompt「图片 1 为首帧」）@720p | 0.5046 / 0.4940 | **不锁 frame0**（与参考图位同级） |
| prompt-first @480p | 0.4238 / 0.4224 | 不锁；输出仍 1254×720（resolution 未生效） |
| 对照：`--generate-type 1` 首尾帧同图 @720p（校准） | **0.9275** | 锁定 |

- 4 次共 80 credits（~20/次，与 720p 一致）→ 直连 CLI 无 480p 降本空间。
- **结论**：E1 的 A 组继续用 `--generate-type 1`；手册的 prompt 首帧声明属于 web/沉浸式短片 R2V 通道，不能映射到直连 CLI。
